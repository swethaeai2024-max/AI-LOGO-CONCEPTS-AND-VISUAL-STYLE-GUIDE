# NEXOURA AI

NEXOURA AI is a modern branding and logo concept workspace built with React and Vite. It gives users a clean dashboard for creating brand identities, previewing logo concepts, selecting color palettes, exploring typography, and preparing export-ready brand assets.

## Project Overview

This project is designed as a creative AI branding workspace where users can:

- Create a brand name and tagline
- Customize industry and primary brand color
- Generate a logo preview concept
- Explore brand tools such as color palette and typography
- Review originality and brand consistency guidance
- Preview mockups and export logo assets

## Features

- Dashboard-based UI with modular creative tools
- Brand Creator for concept ideation
- AI Logo Studio-style preview generation
- Color palette selection
- Typography preview panel
- Brand style guide overview
- Mockup studio previews
- Prompt library for AI design prompts
- Before/after concept comparisons
- Verification report and export center

## Tech Stack

- React 19
- Vite
- JavaScript
- CSS for modern branding UI

## Getting Started

### Prerequisites

- Node.js (v18 or newer recommended)
- npm

### Install dependencies

```bash
npm install
```

### Run the app locally

```bash
npm run dev
```

The development server will start and open the app in your browser (or provide a local URL in the terminal).

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

## Usage

1. Open the app dashboard.
2. Select a tool from the left sidebar.
3. Enter a brand name, tagline, and industry.
4. Choose colors and explore the available branding modules.
5. Generate a logo preview and download the SVG output when ready.

## Notes

This project functions as a front-end concept and design prototype rather than a full backend-powered AI branding platform. The app demonstrates an interactive UX for brand identity generation and export.
