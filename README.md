# 💜 NEXOURA AI
### Imagine. Design. Inspire.

## 📌 Project Title
AI-Powered Logo Concept Generator and Brand Identity Studio

## 📝 Project Description
NEXOURA AI is a creative brand identity platform designed to help users create logo concepts and develop professional brand identities using modern web technologies.

## 🎯 Objectives
- Create logo concepts.
- Generate brand color palettes.
- Select suitable typography.
- Create brand style guides.
- Preview brand mockups.
- Save and reuse creative prompts.
- Compare logo concepts.
- Prepare verification reports.
- Export logo assets.

## ✨ Key Features
1. Dashboard
2. Brand Creator
3. AI Logo Studio
4. Originality Checker
5. Color Palette Generator
6. Typography Studio
7. Brand Style Guide
8. Mockup Studio
9. Prompt Library
10. Before and After Comparison
11. Verification Report
12. Export Center

## 🚀 How to Run

Install dependencies:

    npm install

Start the development server:

    npm run dev

Open the local URL displayed in the terminal.
